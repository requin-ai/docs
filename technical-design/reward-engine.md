# Reward Engine & Tokenomics

Requin Hub includes a built-in reward system that measures usage of MCP servers
and rewards their owners in Requin Token (REQ) and project-specific tokens.

## Flow
1. MCP server sends usage data via SDK.
2. Requin Hub aggregates logs.
3. Reward Engine calculates Requin Points.
4. Points convert to tokens on each reward cycle.
