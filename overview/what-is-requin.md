# Overview

## What is Requin MCP Hub?

**Requin MCP Hub** is a decentralized platform that connects, indexes, and rewards **MCP servers** and their creators.  
It serves as both a **registry** for discovering MCP-compatible projects and a **deployment platform** powered by the **Requin Token (RQN)**.

Developers can:
- Submit or host their MCP servers directly.
- Deploy existing MCP servers with Requin or other currencies.
- Earn rewards in Requin tokens based on the usage of their deployed servers.

---

## Why Requin?

The MCP ecosystem is growing fast — with hundreds of servers appearing across GitHub and independent deployments.  
However, there’s no unified directory or incentive model to encourage developers to maintain high-quality MCP services.

Requin fixes this by:
- **Indexing** all known MCP servers through scrapers and submissions.
- **Rewarding** server owners for usage via a transparent on-chain model.
- **Allowing deployment** through fiat, crypto, or Requin tokens.
- **Creating new tokens** for each project, enabling trading and speculative markets.

---

## Core Features

| Feature | Description |
|----------|--------------|
| 🧩 **MCP Registry** | Automatically indexes MCP servers from GitHub and other sources. |
| 🚀 **Server Deployment** | Deploy and manage MCP servers using Requin token or other payment methods. |
| 💰 **Rewards System** | Earn Requin tokens based on your server’s real-world usage. |
| 🪙 **Project Tokens** | Each MCP project can launch its own token tied to usage metrics. |
| 📈 **Marketplace** | Track token value, usage stats, and performance metrics of servers. |
| ⚙️ **Requin SDK/API** | Allows developers to integrate usage tracking and reward reporting. |

---

## Example Flow

1. A developer publishes a new MCP server to GitHub.  
2. The Requin Hub scraper indexes it automatically.  
3. The developer claims ownership and integrates the Requin SDK.  
4. As users interact with the server, usage data is recorded.  
5. The developer earns Requin tokens based on traffic and engagement.  
6. Optionally, they can launch a unique token for their project that trades on DEXs.  

---

## Requin Token (RQN)

Requin is the **native token** powering the ecosystem.  
It is used for:
- Paying for deployments.
- Rewarding MCP creators based on server usage.
- Participating in governance and platform staking.
- Enabling liquidity between project-specific tokens and the Requin economy.

---

## The Vision

Requin MCP Hub aims to become the **“app store” for MCP servers** —  
where every developer can publish, every user can deploy, and every contributor can earn.

Our long-term goals include:
- AI-assisted ranking and discovery of servers.
- Cross-chain token rewards and analytics.
- Decentralized governance through RQN staking.
