# Core Concepts

## 1. Earning for MCP Server Owners

Every MCP server listed or deployed through **Requin Hub** can generate revenue for its creator.

### How It Works
- Each server integrates the **Requin SDK** or API to report usage metrics (e.g., requests, calls, sessions).  
- The Requin backend tracks usage in real time and converts it into **Requin Token (RQN)** rewards.  
- The more your server is used, the more Requin you earn.

Rewards are distributed automatically based on verifiable usage data.  
This creates an **open economy of compute and intelligence**, where developers are paid for the real value their MCP servers deliver.

---

## 2. Co-Ownership Through Tokens

Every deployed MCP server can issue its own **project token** — a tradable asset that represents a share of ownership or participation in that specific server’s ecosystem.

### Key Ideas
- When a new MCP server is published or deployed, a **unique token** is minted.  
- These tokens are tradable on DEXs and tracked within Requin Hub.  
- Holding these tokens can grant:
  - A share of that server’s usage rewards.
  - Governance or reputation influence within the project.
  - Access to premium server features or higher quotas.

This allows anyone to **co-own AI and compute infrastructure**, not just use it.

---

## 3. Deployment as a Service

Requin Hub provides **Deployment-as-a-Service (DaaS)** for MCP servers.

### Capabilities
- Deploy your own MCP server directly from GitHub or any supported source.  
- Pay for deployment in **Requin tokens (RQN)** or other currencies (crypto or fiat).  
- Requin handles the hosting, scaling, and operational monitoring automatically.

Each deployment is connected to your wallet and Requin profile, enabling:
- Seamless tracking of usage → rewards.
- Direct integration with your project token.
- Access to analytics and performance dashboards.

---

## 4. The Requin Ecosystem Flywheel

1. **Discover:** Users find MCP servers on Requin Hub (scraped or submitted).  
2. **Deploy:** They deploy the servers using Requin or other payment options.  
3. **Use:** End-users interact with the deployed MCP servers.  
4. **Earn:** Server owners and token holders receive rewards in RQN.  
5. **Reinvest:** Tokens can be used to deploy more servers or traded on DEXs.  

This creates a **self-sustaining circular economy** for AI infrastructure, driven by usage and tokenized incentives.
